# 食品營養華語文獻閱讀｜互動教學工具

**Food Nutrition Academic Chinese Reading — Interactive Teaching Materials**

A2–B1 Chinese language course using food/nutrition industry articles as reading material.  
This repository contains the **interactive HTML tools** and **anonymized class reports** used in class.

---

## 課程設計 / Course Design

| Phase | Weeks | Method |
|-------|-------|--------|
| 期中考前 Pre-midterm | W1 | Traditional PPT |
| 期中考後 Post-midterm | W2–W4 | Interactive HTML tools + Supabase real-time data |

### Topics Covered (W1–W4)

- **W1** 替代蛋白 Alternative Proteins (General Class)
- **W2** 替代蛋白 Alternative Proteins (University Class)
- **W3** 食品包裝綠色革命 Green Packaging Revolution
- **W4** 無可可巧克力 Cocoa-Free Chocolate

## 技術架構 / Tech Stack

- **Frontend**: Vanilla HTML + CSS + Chart.js
- **Backend**: Supabase (real-time game scores, attendance, polls)
- **Deployment**: GitHub Pages

---

## 教學實踐研究 / Teaching Practice Research

This course is part of a **teaching practice research project** comparing:
- Traditional lecture (PPT) vs. interactive HTML tools
- Research instruments: Supabase interaction logs + end-of-semester student survey
