# 第一學期讀寫手寫動畫

[動畫總覽](index.html) · [原課程](../index.html) · [使用與來源](about.html)

16個教學週，每週閱讀方法、寫作引導各一章，共32章、224幕、64個作答停頓。涵蓋W01–08與W10–17；W09、W18保留考試安排。含臺灣中文女聲、繁體字幕、原教材拼音與越南文，無背景音樂。

播放器支援播放／暫停、拖曳、調速、上一幕／下一幕、重新開始。題目先呈現，停下後按繼續才揭答。每章的`player.html`、`index.html`與`assets/`需一起保留。手寫字型動畫不是漢字筆順教學。

原課文、既有影片、遊戲、寫作與追蹤程式維持原樣；入口由`../handwrite_links.js`加入。微課短文為教學改寫與新增練習，模擬圖表與包裝均有標示。W11明示原課文的先後矛盾，依FAO／Codex定義整理為先冷凍、再包冰。

W16／W17練習字數採中文字、不含標點，與原寫作區計數器不同，繳交規則依教師指定。來源與使用方式詳見`about.html`。

原始程式與素材作者：阿亮老師（曾慶良）／3A科技研究社。各章`assets/fonts/`與`assets/vendor/`保留原授權及來源說明。
